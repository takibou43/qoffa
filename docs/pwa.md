# PWA — قُفّة

تطبيقات **الزبون** و**المحل** و**الموصّل** قابلة للتثبيت. لوحة الإدارة ليست PWA عمدًا.

## المكوّنات

| الملف | الدور |
|---|---|
| `public/manifest.webmanifest` | الاسم، الأيقونات، `display: standalone`، `dir: rtl`, `lang: ar` |
| `public/icons/icon-192.png` · `icon-512.png` · `icon-maskable-512.png` | الأيقونات |
| `public/sw.js` | Service Worker |
| `public/offline.html` | صفحة بديلة عند انقطاع الاتصال |
| `src/main.tsx` | تسجيل الـSW في وضع الإنتاج فقط |

## قواعد الأمان المطبَّقة

1. **لا تخزين لأي رد من `/api`** — طلبات المستخدمين وبياناتهم لا تُكتب في الكاش إطلاقًا.
2. **لا تدخّل في الكتابة** — الـSW يتجاهل كل ما ليس `GET`، فلا يمكن أن يعبث بإنشاء أو تعديل طلب.
3. **لا عمليات دون اتصال** — لا توجد طوابير مؤجّلة؛ انقطاع الشبكة يعني رسالة خطأ واضحة أو صفحة `offline.html`.
4. **كاش للأصول الثابتة فقط** مع تحديث في الخلفية.
5. تنظيف الإصدارات القديمة عند التفعيل.

## الاختبار محليًا

الـSW يعمل في وضع الإنتاج فقط:

```bash
npm run build -w frontend-customer
npm run preview -w frontend-customer
```

ثم في DevTools → Application: تحقّق من Manifest، ومن Service Worker، ومن أن Cache Storage **لا يحتوي أي مسار `/api`**.

> التثبيت على الأجهزة يتطلب **HTTPS** (باستثناء `localhost`).

## غير مشمول

Push Notifications تحتاج خدمة خارجية — خارج نطاق هذه النسخة. الإشعارات حاليًا داخل التطبيق عبر `/api/notifications`.
